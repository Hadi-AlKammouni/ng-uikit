# Demo media

Place the screen recording here as `demo.gif`.

Recommended capture for Ng-UIKit:
1. Land on the Home page. Pause on the hero + install code.
2. Click "Browse components" → Button page → demonstrate variants + loading + disabled.
3. Switch to Modal page → click the danger button → ESC out → focus visibly snaps back to the trigger.
4. Switch to Toast page → click each variant → watch them stack in the top-right and auto-dismiss.
5. Switch to Table page → click a header to sort ascending, click again for descending, paginate.
6. Switch to Tabs page → demonstrate keyboard arrow navigation between tabs.
7. End on the Tokens page → toggle the theme in the topbar to show the whole site re-paint.

Keep the total under 30 seconds. Capture at 1280×720 or 1440×900.
