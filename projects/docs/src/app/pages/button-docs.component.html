Accessibility

  • Renders as a native <button> or <a>; keyboard activation, focus order, and form participation are all native.
  • Visible focus ring at 2 px in the accent color (offset for contrast against any surface).
  • loading sets aria-busy and aria-disabled; the spinner is aria-hidden so it doesn't pollute screen-reader output.
  • Respects prefers-reduced-motion — the spinner animation is reduced to a static frame.
