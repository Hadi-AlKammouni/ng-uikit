What ships in v1

  • Button — 4 variants × 3 sizes, loading state, icon support.
  • Input + Form field — labelled, hint & error states, reactive-forms-ready.
  • Modal — CDK Overlay, focus trap, ESC + backdrop dismiss, focus restoration.
  • Toast — service-driven, stacked, auto-dismiss, ARIA live regions.
  • Data table — sortable columns, pagination, empty & loading states.
  • Tabs — full arrow-key navigation, animated active state.

Design decisions

  • CSS custom properties for theming. Every visual token (color, spacing, type) is a CSS variable. Dark/light themes are a one-attribute toggle, no JS, no bundle cost.
  • CDK over hand-rolled overlays. Modal and Toast use Angular CDK's Overlay + FocusTrap — battle-tested for accessibility (focus restoration, ESC handling, scroll lock).
  • Standalone components only. No NgModules. Consumers import individual symbols and pay only for what they use.
  • Attribute-selector buttons. <button uikitButton> keeps native semantics, type ahead, form integration, and focus behaviour.
