Accessibility

  • The dialog has role="dialog", aria-modal="true", and is labelled by its title (or a fallback aria-label when titleless).
  • Focus is trapped inside the modal using @angular/cdk/a11y ConfigurableFocusTrap.
  • On close, focus is restored to whichever element opened the dialog — try opening a modal, closing it with ESC, and notice the trigger button highlights again.
  • Backdrop click and ESC dismiss are independently opt-out via closeOnBackdrop / closeOnEscape.
